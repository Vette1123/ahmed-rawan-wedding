# دعوة زفاف أحمد و روان

Single-file wedding invitation: sealed envelope intro, hero, scratch-to-reveal date, timeline, countdown, venue map, WhatsApp RSVP, background music.

Live: https://vette1123.github.io/ahmed-rawan-wedding/

## Edit

All event data lives in the `INVITE` block near the bottom of `index.html` (names, date, venue, map link, timeline, RSVP phone numbers). `MUSIC_DELAY` sets how long after opening the envelope the music starts.

Open `index.html` directly, or serve the folder:

```
python -m http.server 8765
```
